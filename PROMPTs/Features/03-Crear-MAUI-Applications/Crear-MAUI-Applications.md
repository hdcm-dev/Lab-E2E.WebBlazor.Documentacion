## Solicitudes

  Crear en base al proyecto `MovilidadUrbana.Web` una versión dada en un MAUI Web Dot NET 10 con dos controllers uno para localidades y otro para la encuesta, el proyecto nuevo debería llamarse `/MovilidadUrbana.MAUI` . Respeta la arquitectura clean. sigue los estandares de la industria en .net. Incluir dentro de la aplicación la base de datos , debe ser totalmente indenpendiente. Incluir el workflow para constrir en android. Tenes Un dispsoitivo android conectado como desarrollador por usb para hacer pruebas y asegurarte que funciona y que el diseño cumple con los estandares de diseño de aplicaciones en cuanto a los criterios propios del diseño UX - UI. Experiencia de usuario y flujo de usuario optimos. Revisa y mejora la aplicación tantas veces como sea necesario. Utiliza un devcontainer para depurar con el dispositivo local conectado.
